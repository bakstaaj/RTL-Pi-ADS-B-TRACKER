# RTL Pi ADS-B Tracker v2.0.0

## Major Release Summary

This release establishes the Raspberry Pi RTL-SDR ADS-B Tracker as an integrated map-first receiver application with ADS-B tracking, NOAA Weather listening, Airband background scanning, aircraft enrichment and persisted trail history.

## Highlights

- Live ADS-B aircraft map with active-aircraft list, altitude-colored trails and receiver-centered range rings.
- Raspberry Pi stored trail history with clear/restore controls.
- Trail hover display with callsign or ICAO fallback, last-seen timestamp and AirLabs route information when available.
- Aircraft detail lookup with ADSBDB aircraft/photo enrichment, FAA tail-number support and AirLabs From/To route enrichment.
- Secure in-app AirLabs API key management stored only on the Pi.
- Two-hour successful AirLabs route cache with a manual clear-cache control.
- NOAA Weather listening using the dedicated RTL-SDR receiver, including auto-select and persistence of the local NOAA channel.
- Airband background scanning with NOAA handoff and map-footer display of the currently tuned AM frequency.
- Dedicated configurable Airband scan radius that can be changed without clearing the saved NOAA channel selection.
- Receiver location entry plus map-based location selection.

## Hardware Baseline

- Raspberry Pi 5
- ADS-B RTL-SDR serial: `00001090`
- NOAA / Airband RTL-SDR serial: `00000162`

## Release Validation

The release script verifies Python syntax and confirms the expected UI/backend markers for Airband, NOAA, AirLabs, trail hover, map location selection and route-cache support before committing and tagging.
