# RTL ADS-B Tracker v3.3.1

## Release focus

v3.3.1 is a V3 patch release that keeps the current V3 application line and adds a receiver-location UI cleanup before the next full fresh-install validation.

## Functional changes

### Receiver location UI refinement

- Moves the receiver "pick location on map" control into the receiver-location control group.
- Keeps the map-pick action with the receiver name, latitude, and longitude fields.
- Uses runtime DOM placement so the control stays correctly grouped even when the menu markup is generated dynamically.

### Install/bootstrap carry-forward

This patch release keeps the current V3 bootstrap behavior, including:

- Runtime-only Raspberry Pi dependency install.
- No installer-owned apt update.
- App-owned ARM64 readsb deployment.
- Standard aircraft JSON path:
  - `/run/rtl-pi-readsb/aircraft.json`
- Final LAN IP / direct web UI URL display at the end of install.

## Web UI access

After install, open:

```text
http://<pi-lan-ip>:8090
```
